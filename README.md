## ▶️ Run Locally

### Prerequisites

- Node.js 18+
- npm, pnpm, or yarn

### Installation

```bash
git clone https://github.com/muthuvel-24/portfolio.git
cd portfolio
npm install
npm run dev
```

Open the local development URL shown by Vite.

### Production build

```bash
npm run build
npm run preview
```
